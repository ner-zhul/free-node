# Free Node

聚合多个公开数据源的免费代理节点订阅，每 24 小时自动更新一次。

## 订阅地址

推荐使用 jsDelivr：

```text
https://cdn.jsdelivr.net/gh/ner-zhul/free-node@master/src/proxy.yml
```

备用地址（GitHub Raw）：

```text
https://raw.githubusercontent.com/ner-zhul/free-node/master/src/proxy.yml
```
